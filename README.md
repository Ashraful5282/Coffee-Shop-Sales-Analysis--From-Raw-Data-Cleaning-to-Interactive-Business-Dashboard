#Coffee Shop Sales Analysis: From Raw Data Cleaning to Interactive Business Dashboard

# Project Overview
Developed an interactive Coffee Shop Sales Dashboard using Microsoft Excel to analyze sales performance, identify customer purchasing patterns, and explore sales distribution across different countries.

The project involved cleaning and preparing raw datasets, integrating information from multiple worksheets, performing sales calculations, and building an interactive dashboard to present meaningful business insights.

# 1. Data Cleaning & Preparation
- Integrated customer information into the Orders worksheet using **XLOOKUP**.
- Retrieved product information, including Coffee Type, Roast Type, Size, and Unit Price, using the **INDEX** function.
- Identified missing values and preserved them as blank cells rather than replacing them with zero.
- Standardized abbreviated coffee and roast types into understandable descriptions.
- Calculated sales using Quantity × Unit Price.
- Applied consistent date, weight, and currency formatting.
- Converted the cleaned dataset into an Excel Table for better data management.

# 2. Data Analysis
Analyzed the prepared dataset to explore:
- Sales trends over time.
- Sales performance across different countries.
- Top 5 customers based on sales.
- Sales distribution across different coffee types.

#3. Interactive Dashboard Development
Designed an interactive Excel dashboard featuring:

- **Total Sales Over Time:** A line chart displaying sales trends across different coffee types.
- **Sales by Country:** A horizontal bar chart comparing sales performance across countries.
- **Top 5 Customers:** Identified the five highest-value customers based on sales.
- **Interactive Slicers:** Enabled filtering by Roast Type Name, Product Size, and Loyalty Card status.
- **Timeline Filter:** Implemented a date timeline to explore sales performance across different periods.
